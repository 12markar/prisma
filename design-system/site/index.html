— design philosophy / 001
01 — Philosophy

Technical-precise, with editorial warmth.

Most systems collapse into one of two failure modes: the cold dashboard or the over-decorated brand showcase. Prisma takes a third path — the visual register of a well-set technical journal.

001

Type carries the design.

A confident type scale with deliberate weight pairings does most of the visual lifting. Color marks state and intent — never decorates.

002

Surfaces have a temperature.

Backgrounds are warm-neutral, never pure white or pure black. The palette reads as considered, and stays kind to the eye over long sessions.

003

Idiomatic, not opinionated.

Tokens are designed to feel native on both platforms. iOS-style soft shadows in light mode; subtle borders + glows in dark mode. A 4pt grid that maps cleanly to dp and points.

02 — Tokens

Two layers. One source of truth.

Eleven-stop primitive ramps for raw values. Semantic aliases for the components that consume them. Compiled through Style Dictionary into Tokens.kt and Tokens.swift — never copy-pasted.

03 — Typography

Instrument Sans meets JetBrains Mono.

Two faces, one voice. A humanist sans for prose and UI; an engineered mono for data and code. The contrast is intentional.

05 — Native

One language. Two platforms.

Tokens compile to native sources — no bridge, no runtime. Components are specified for Compose and SwiftUI separately, but they share the same anatomy, the same a11y contracts, and the same name.
