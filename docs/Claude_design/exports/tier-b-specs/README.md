# Prisma — Tier B Component Specs

Refined specs for the four design-sensitive components flagged in the audit. Each spec covers anatomy, sizing, motion, states, accessibility, and `do/don't` guidance — tuned to Prisma's tokens and motion vocabulary.

## Files
| File | Component |
|---|---|
| `slider.md` | Slider — track + thumb ratios, halo, range/stepped variants |
| `tooltip.md` | Tooltip — caret geometry, position math, flip strategy, timing |
| `popover.md` | Popover — caret + position math, focus management, dismissal |
| `segmented-control.md` | Segmented control — chip slide easing, pressed flash specifics |
| `command-palette.md` | Command palette — group hierarchy, recent / results / no-results states |

## How to use
Drop these into `design-system-output/component-specs/` alongside the existing 14. They use the same token names so they slot directly into the Style Dictionary pipeline.
